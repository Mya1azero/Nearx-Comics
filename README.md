# NearX Comics

Студия персональных комиксов: загружаешь фото — получаешь себя героем нарисованной книжки.
Фото → лист героя → история (текст или голос) → ИИ-сценарий по страницам и кадрам с диалогами
(всё редактируется) → отрисовка страниц в двойной чёткости → альбом с обложкой и скачиванием.

## Запуск

```bash
cd neo3-visual && npm install
cd ../site && npm install
node server.cjs        # порт 3777 (или PORT из окружения)
```

Переменные окружения (или файлы `.env` в соответствующих папках):

- `KIE_API_KEY` — ключ kie.ai (генерация картинок), можно в `neo3-visual/.env`
- `TG_BOT_TOKEN` — токен телеграм-бота показа (опционально), можно в `bot/.env`
- `OPENROUTER_API_KEY` — мозг сценариста (без него — деморежим), можно в `site/.env`

## Деплой на Render

Репозиторий содержит `render.yaml`: New → Blueprint → выбрать этот репозиторий →
вставить три ключа. Диск на бесплатном тарифе эфемерный: готовые страницы живут до
рестарта — пользователь скачивает ZIP сразу, копии улетают в телеграм.

## Устройство

- `site/` — веб-студия: `server.cjs` (API + статика), `worker.cjs` (отрисовка заявки,
  detached), `llm.cjs` (сценарист через OpenRouter), `prompt.cjs` (боевые шаблоны промптов).
- `neo3-visual/` — движок генерации (CLI `vis`): бюджет-предохранитель в `budget.json`,
  журнал трат `out/ledger.jsonl`, правила ремесла в `skills/comics/SKILL.md`.
- `bot/` — телеграм-доставка готовых страниц владельцу.

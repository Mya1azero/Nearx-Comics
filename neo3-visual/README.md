# Neo³ Visual (`vis`)

Генерация картинок и рекламных креативов через [kie.ai](https://kie.ai) — агрегатор
моделей (GPT Image 2, Nano Banana 2, Seedream, Flux, Ideogram, Qwen, Imagen).
Подписки нет, платим за факт генерации, пополнение с российской карты по СБП.

**Главная идея:** один промпт → N вариантов от РАЗНЫХ моделей за раз. Пока не
попробовал, не угадаешь, какая модель поймёт именно этот продукт. Шесть картинок
в 1K стоят ~30 кредитов ≈ $0.15 — дешевле, чем угадывать и переделывать.

## Установка — одна команда

Нужен Node.js 18+ (`brew install node`) и ключ с [kie.ai](https://kie.ai)
(регистрация → API Key → пополнение, с российской карты по СБП).

```bash
git clone https://github.com/dimasikk25155/neo3-visual.git && cd neo3-visual && ./install.sh
```

Установщик сам поставит зависимости, сделает команду `vis` глобальной, спросит
ключ, скачает шрифт, подключит скилл к Claude Code и проверит связь с kie.ai.
Запускать повторно безопасно.

Ключ живёт в файле `.env` в папке проекта, в git не попадает. Порядок поиска:
переменная окружения → `.env` → файл из `NEO3_SECRETS` (для тех, у кого свой
общий склад ключей).

## Быстрый старт

```bash
vis crea "промпт" --format post --dry-run    # план и цена, кредиты не тратит
vis crea "промпт" --format post --text "ЗАГОЛОВОК|В ДВЕ СТРОКИ" --subtext "уточнение"
vis gallery && open gallery.html   # выбрать глазами: модель, цена, промпт под каждым кадром
```

С Claude Code проще: скилл подключается установщиком, дальше можно просто просить
словами — «сделай пять креативов под запуск очков, формат сторис».

## Комиксы (наша надстройка)

Один сценарий JSON → кадры ОДНОЙ моделью (герой держится на референсе и общем
стиле) → реплики и подписи рисуются кодом → готовая страница `page.jpg`.
Правка текста и раскладки — бесплатно, перегенерация не нужна.

```bash
vis comic --example > сценарий.json   # шаблон с подсказками
vis comic сценарий.json --dry-run     # план и цена (4 кадра ≈ $0.16)
vis comic сценарий.json               # генерация + пузыри + страница
vis comic сценарий.json --assemble out/ПАПКА   # переверстать текст, 0 кредитов
```

Пузыри: speech / thought (мысль) / shout (звезда крика) / caption (подпись);
якоря и хвосты — в `skills/comics/SKILL.md`. Раскладки: `grid` (страница
2 колонки), `strip` (лента для Telegram), `wide` (все кадры в ряд). Новые
модули: `src/comic.js` (план/генерация/сборка) и `src/bubbles.js` (геометрия
пузырей); генерация кадров ходит через тот же клиент, журнал и предохранитель,
что и `crea`.

## Что здесь своё, а что взято

Каркас работы с API kie.ai — форк [nick-vels/VelsVisual](https://github.com/nick-vels/VelsVisual)
(MIT): `src/kie/` — клиент шести семейств API, живой каталог моделей из
`docs.kie.ai/llms.txt`, разбор схемы модели прямо со страницы её документации,
живой прайс-лист. Благодаря этому модель, вышедшая вчера, работает без правок кода.

Дописано с нуля — то, чего в оригинале нет:

| Модуль | Зачем |
|---|---|
| `fanout.js` | N вариантов от разных моделей одним запуском, параллельно; референс загружается один раз на всю пачку |
| `budget.js` | предохранитель расходов **в коде**, а не текстом в инструкции для агента |
| `overlay.js` | надпись накладывается кодом: заголовок + подстрока, точный шрифт, обрезка кадра под формат |
| `presets.js` | форматы площадок и подгонка их под то, что реально умеет каждая модель |
| `ledger.js` | паспорт рядом с каждым кадром + журнал расходов |
| `gallery.js` | одностраничная галерея для выбора глазами |

Убрано: музыка, озвучка, апскейл, визард установки.

## Форматы под рекламу Meta

| Пресет | Соотношение | Куда |
|---|---|---|
| `post` | 4:5 (1080×1350) | **основной для лент** Facebook и Instagram: на мобильном занимает на 25% больше экрана, чем квадрат, и не режется на десктопе |
| `story` | 9:16 (1080×1920) | Stories и Reels — единственный формат, заполняющий экран телефона целиком |
| `square` | 1:1 | универсальный запас для Advantage+ |
| `wide` | 16:9 | обложки, hero сайта |

`4:3` — это **горизонталь**, для вертикальной рекламы не подходит.

## Бюджет

`budget.json` — три рубежа: лимит на один запуск (`perRunUsdCap`), общий потолок
по журналу (`totalCreditsCap`) и предупреждение при большой доле баланса.
Превышение = отказ с ненулевым кодом выхода. Это защита от самого агента:
правило «посчитай цену» в тексте скилла модель может проигнорировать, проверку
в коде — нет.

## Грабли

- **Шрифты только из `~/Library/Fonts`.** На macOS текст в sharp рисует CoreText:
  папку проекта он не сканирует, опцию «файл шрифта» игнорирует и **молча**
  подменяет шрифт на системный. `vis font` ставит куда надо сам. Кэш шрифтов
  обновляется с задержкой пары секунд.
- **Цена «(оценка)»** — у модели нет машинного id в прайсе kie.ai (например,
  у nano banana 2), цена подобрана по описанию. При неоднозначности берётся
  дорогой тариф: предохранителю положено переоценивать расход.
- **Цена зависит не только от разрешения**: у ideogram — от `rendering_speed`,
  у seedream — от `quality`. Одна модель стоит от 3.5 до 22 кредитов.
- **Часть моделей маркета нерабочая**: `ideogram/v3-remix` отдаёт 500,
  `ideogram/v3-edit` требует маску (это инпейнтинг), `flux-kontext-pro` возвращает
  пустой результат, у `bytedance/seedream-v4-edit` нет цены в прайсе. Пачка не
  откатывается: остальные модели доводятся до конца.
- **Имя поля для референса у вендоров разное, и список известных имён отстаёт.**
  Nano Banana 2 / Pro / Lite принимают картинку в поле `image_input` — его в
  унаследованном списке не было, и все три модели выглядели как text-to-image и
  молча выпадали из пачки. Добавлен запасной поиск: любое поле, похожее на
  картинку, с приоритетом массива.
- **Связь с kie.ai (за ним Cloudflare) из России моргает.** Половина параллельных
  задач падала с «fetch failed», хотя повтор через секунду проходил. Запросы и
  скачивания повторяются автоматически (GET 3 попытки, POST 2, скачивание 3).
- **Упавшая генерация тоже стоит денег.** kie.ai списывает кредиты при создании
  задачи, а не при выдаче результата. Журнал пишет расход сразу после создания,
  но обрыв сети может его потерять — поэтому есть `vis reconcile`: сверяет журнал
  с реальным балансом (`startingBalance` в `budget.json`) и дописывает поправку.
  Саму картинку терять не обязательно: `vis fetch <taskId>` забирает результат
  уже оплаченной задачи в течение ~24 часов, повторно не списывая.
- **Не все модели знают нужное соотношение сторон** — берётся ближайшее, кадр
  дорезается после скачивания. В плане это видно как «→ дорежем».

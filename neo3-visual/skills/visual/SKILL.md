# vis — рекламные креативы и картинки через kie.ai

Свой инструмент (форк идей VelsVisual, но наш код): папка этого репозитория,
команда `vis` доступна глобально. Платим за факт генерации, подписки нет.
Ориентир цен: одна картинка 1K — 3.5–8 кредитов ($0.018–0.04), 1 кредит = $0.005.

## Железные правила

1. **Никогда не выдумывай id модели.** Каталог живой: `vis models --search seedream`.
   В `--models` пиши только то, что вернул каталог, либо не пиши вовсе — тогда
   состав возьмётся из тира.
2. **Сначала `--dry-run`, потом деньги.** Всегда прогоняй план, назови хозяину
   модели и итоговую цену в кредитах и рублях/долларах, и только потом запускай
   без `--dry-run`. Исключение: он сам сказал «просто сделай» и цена меньше $0.20.
3. **Спроси подтверждение**, если запуск дороже $0.20, или если хозяин не задал ни
   формат, ни количество (уточни формат и число вариантов — это дешевле, чем
   переделывать).
4. **Черновик — дешёвым тиром.** Ищем идею на `--tier cheap` (1K). Дорогой прогон
   (`--tier quality`, 4K) — только для одного УТВЕРЖДЁННОГО варианта.
5. **Текст накладывай кодом, не промптом.** Никогда не проси модель написать
   надпись на картинке — получишь кривые буквы. Передавай `--text`. Правка
   надписи через `vis text` стоит **0 кредитов** — правь сколько нужно.
6. **Посмотри на результат глазами.** После генерации прочитай файлы (Read) и
   проверь: текст не залез на продукт, не срезано лицо/логотип, читается на фоне.
   Нашёл проблему с ТЕКСТОМ — переналожи через `vis text` (бесплатно). Проблема в
   самом кадре — только тогда перегенерируй, и скажи хозяину, что это новые деньги.
7. **Бюджет проекта — предохранитель в коде.** Он вернёт отказ и объяснит причину.
   НЕ обходи его через `--max-usd` и не правь `budget.json` по своей инициативе —
   только если хозяин явно разрешил.

## Порядок работы

```bash
vis spent                                    # сколько осталось из бюджета проекта
vis crea "промпт" --format post --dry-run    # план и цена, денег не тратит
vis crea "промпт" --format post --text "..." # запуск
```

После запуска сообщи хозяину: сколько списано, папку с результатами и что галерея
`gallery.html` обновлена. Затем посмотри кадры и скажи, какой считаешь лучшим и почему.

## Команды

```bash
vis crea "промпт" [флаги]      # N вариантов от разных моделей
vis text ФАЙЛ --text "..."     # переналожить надпись (0 кредитов)
vis credits                    # баланс kie.ai
vis spent                      # расход из бюджета проекта
vis models [--search X]        # живой каталог моделей
vis price МОДЕЛЬ [--resolution 1K|2K|4K]
vis gallery                    # пересобрать галерею
vis reconcile                  # сверить расход с реальным балансом kie.ai
vis fetch TASK_ID              # забрать оплаченный результат после обрыва связи (не списывает)
vis font "Unbounded"           # поставить шрифт Google Fonts
vis rosters                    # какие модели входят в тиры
```

Флаги `crea`: `--models auto:6|id,id` · `--tier cheap|quality` · `--format square|post|story|wide|landscape|portrait|W:H`
· `--ref ФАЙЛ` (можно несколько) · `--text "СТРОКА|СТРОКА"` · `--font` · `--position top|center|bottom`
· `--resolution` · `--max-usd` · `--set поле=значение` · `--dry-run` · `--json`

## Как формулировать промпт для креатива

Хозяин обычно даёт задачу словами («крео под очки для соцсетей»). Разверни её в
промпт сам, по схеме: **продукт → окружение/поверхность → свет → ракурс → стиль**.

```
"близкий кадр: солнцезащитные очки на мокром чёрном камне, капли воды,
 жёсткий контровой свет, отражения в линзах, студийная реклама, кинематографично"
```

Чего НЕ писать в промпте: текст надписи, логотип словами, номер формата.
Надпись — через `--text`, логотип — через `--ref файл`, формат — через `--format`.

## Референсы (логотип, фото товара)

Есть файл товара или логотипа — обязательно `--ref`: описать логотип словами
невозможно, получится каша. Файл загружается один раз и переиспользуется всеми
моделями пачки. С `--ref` инструмент сам переключается на image-to-image модели.

```bash
vis crea "банка энергетика на бетоне, брызги, контровой свет" \
    --ref ./logo.png --format post --text "СКОРОСТЬ|В КАЖДОМ ГЛОТКЕ" --font Unbounded
```

## Форматы

`square` 1:1 (лента) · `post` 4:5 (вертикальный пост) · `story` 9:16 (сторис, шортсы)
· `wide` 16:9 (обложка, hero сайта) · `landscape` 3:2 · `portrait` 2:3.

Не все модели умеют нужное соотношение — инструмент берёт ближайшее и дорезает
кадр сам. Это нормально и видно в плане («→ дорежем»).

## Шрифты

Шрифт должен стоять в системе: `vis font "Unbounded"` (ставит в `~/Library/Fonts`).
Папка `fonts/` в проекте — только копия для истории, sharp её НЕ видит. Если после
установки первый рендер вышел системным шрифтом — подожди пару секунд, кэш macOS
обновляется с задержкой, и переналожи текст (бесплатно).

## Грабли

- **Цена «(оценка)»** — у модели нет машинного id в прайсе kie.ai, цена подобрана
  по описанию. Так и скажи хозяину: списание может отличаться, сверь `vis credits` после.
- **Модель упала, остальные прошли** — это нормально, пачка не откатывается.
  НО: kie.ai списывает кредиты в момент создания задачи, поэтому за упавшую
  генерацию деньги могли уйти. После прогона с падениями запусти `vis reconcile` —
  он сверит журнал с реальным балансом и допишет поправку.
- **«сетевая ошибка: fetch failed» НЕ значит «бесплатно».** Связь с kie.ai из
  России моргает; если задача успела создаться — деньги списаны. В выводе `crea`
  теперь видно, сколько кредитов ушло за недошедшие результаты. Такие кадры
  вытаскивай через `vis fetch <taskId>` (taskId лежит в `out/ledger.jsonl`,
  ссылки живут ~24ч) — это бесплатно. НЕ перегенерируй молча, это двойная оплата.
- **`451`** — kie.ai не смог скачать референс: перезалей файл (путь должен
  существовать локально, тогда загрузка идёт сама).
- **Нерабочие модели маркета:** `ideogram/v3-remix` отдаёт 500, `ideogram/v3-edit`
  требует маску (это инпейнтинг), `flux-kontext-pro` возвращает пустой результат,
  у `bytedance/seedream-v4-edit` нет цены в прайсе (предохранитель его не пустит).
  Не трать время на их починку — бери другую модель из каталога.
- **Видео пока не поддерживается** — только картинки. Видео дорогое ($0.35 за
  оживление кадра), добавим отдельно.
- Результаты на kie.ai живут ~24 часа, но `vis` скачивает их сразу — файлы уже
  локальные, ничего не потеряется.

## Что лежит рядом с каждым кадром

Файл `01_модель.json` — паспорт: модель, полный промпт, все параметры запроса,
цена, время, taskId. Плюс общий журнал `out/ledger.jsonl` — по нему считается
бюджет и строится галерея. Через месяц по паспорту можно повторить удачный кадр.
